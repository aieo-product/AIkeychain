## エビデンス

### 障害発生時のスクリーンショット

localhost:9999 にプロキシ設定された状態で Claude が `ECONNREFUSED` エラーとなった障害の記録。

> ※ スクリーンショットは個人情報保護のため削除済み

**エラー内容:**
```
API Error: Unable to connect to API (ECONNREFUSED)
```

**原因:** AIkeychain の SetupManager が `.zshrc` に `ANTHROPIC_BASE_URL=http://localhost:9999` を自動書き込みしたが、プロキシサーバー（AIkeychain アプリ）が起動していなかったため、Claude の API 接続が全て失敗。
