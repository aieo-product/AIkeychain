## Proxy セッショントークン認証テスト

```
[Test 1] トークンなし → 403 拒否
$ curl -X POST -H "Host: api.anthropic.com" http://localhost:18121/v1/messages
{"error":"Missing or invalid session token"}
→ OK ✅

[Test 2] 不正なトークン → 403 拒否
$ curl -X POST -H "X-AIKeyChain-Token: WRONG" ...
{"error":"Missing or invalid session token"}
→ OK ✅

[Test 3] 正規トークン → upstream 到達
$ curl -X POST -H "X-AIKeyChain-Token: <sessionToken>" ...
HTTP 401 | first_byte=0.641s
→ OK ✅（401 は Keychain 内 API キー期限切れ、転送自体は正常）
```
