## AI KeyChain とは？

AI開発で必要となる各種APIキー・トークンを **macOS Keychain** で安全に一元管理するネイティブアプリです。

## こんな方に

- `.env` や `.zshrc` にAPIキーを平文で保存している
- AI開発で複数のAPIキー (Anthropic, OpenAI, xAI...) を管理する必要がある
- チームメンバーに安全なキー管理方法を導入したい
- macOS ネイティブのセキュアな管理ツールが欲しい

## クイックスタート

1. AI KeyChain をインストール
2. 初回起動でチュートリアルに従う
3. GitHub トークンを登録 (必須)
4. AI API キーを登録 (推奨)
5. `.zshrc` 用の export 文をコピー

詳細は開発完了後に追記します。
